## 在线“图文成片”工具的三个问题

搜“文章转视频”“图文成片”，首页几乎全是在线 SaaS。它们能用，但对每天要更几条的自媒体来说，有三个绕不过去的点：

1. **排队与额度**：免费档要排队，生成一条等几分钟；批量出片要么加钱，要么一条条点。
2. **水印与订阅**：导出高清常要会员，成片带水印。
3. **素材与文案要上传**：未发布的选题、客户稿、内部资料都要传到别人服务器。

零创走的是另一条路：**安装在本机，批量处理，不上传**。

## 零创的图文成片流程

1. **文案 → 口播稿**：把文章粘进来，自动提炼成适合口播的短句，可手动改。
2. **拆分镜**：按稿子时长自动拆分镜，每 3 秒左右一段。
3. **配画面**：支持「AI 图片生成视频」（逐段出图再运镜），也可以调用自己的本地素材。
4. **配音**：14 款中文音色，支持语速调节（黄金解说语速档）。
5. **字幕与包装**：烧录双行字幕、顶部 Hook 大标题、片头卡、封面帧。
6. **BGM 与成片**：内置 8 首 BGM，本机合成 MP4，成片在软件内直接预览。

## 和在线工具、手动剪辑的区别

| 方案 | 适合谁 | 局限 |
| :--- | :--- | :--- |
| 在线图文成片 SaaS | 偶尔做一条、不想装软件 | 排队、水印、订阅、素材需上传 |
| 手动剪辑（剪映等） | 对画面有精细要求 | 一条条做，批量效率低；口播稿、配音、字幕都要自己拼 |
| **零创** | 每天批量出片的自媒体 | Windows 桌面软件；画面精细度不如专业剪辑，胜在批量与速度 |

## 三步上手

1. 下载安装零创（Windows 10 / 11 64 位）。
2. 打开「AI 视频」，粘贴文案或从「AI 创作」的成稿一键转视频。
3. 选画幅、音色、BGM，点「开始生成高清视频」，成片进「视频成果库」。

## 常见问题

**Q：能批量把多篇文章转成视频吗？**

A：可以。文章列表支持多选批量生成，逐篇转口播稿再出片；批量任务可以随时停止。

**Q：能用我自己的素材，而不是 AI 生成图片吗？**

A：可以。素材调用模式支持「AI 图片生成视频」，也可以使用本地视频素材做混剪。

**Q：配音有多少种？能调语速吗？**

A：内置 14 款中文音色，覆盖男声、女声、解说、情感等风格；语速可调，默认是适合短视频解说的黄金语速。

**Q：字幕是自动的吗？**

A：口播稿会直接烧录成双行字幕，不需要再导入剪映对齐时间轴。

**Q：成片能直接发到头条或抖音吗？**

A：零创的视频能力聚焦在“生成与本地处理”，**不包含向视频平台自动发布**；成片导出后由你自行上传。

**Q：对电脑配置有要求吗？**

A：视频合成在本机完成，配置越好出片越快；普通办公本可以出片，批量任务建议留足磁盘空间。

**Q：收费吗？**
